# NakuruFX Demo — GitHub Pages

A GitHub Pages-ready front-end prototype based on the NakuruFX design.

## Files

- `index.html` — main website
- `style.css` — design and responsive layout
- `app.js` — demo interactions
- `README.md` — setup instructions

## Features

- Professional NakuruFX landing page
- Responsive navigation
- Trading dashboard mockup
- Simulated BUY/SELL order panel
- real wallet section
- real account/login buttons
- Market pair selector
- Simulated changing EUR/USD price
- GitHub Pages compatible
  real-money trading or payment processing

## Run locally

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload all four files.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/root` (or repository root).
6. Save and wait for GitHub Pages to publish.

## Important

This is a front-end real/prototype. It does  execute real trades, accept deposits, process withdrawals, or connect to a broker. Real financial functionality would require a secure backend, authentication, compliance controls, regulated services, and appropriate broker/payment integrations.
